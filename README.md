# Furry Everpony

一个**纯网页**的即时通讯服务。

运营者在一台常开的机器上跑一个后台服务，所有人——包括运营者自己——用浏览器打开网址就能注册、聊天；手机用「添加到主屏幕」（PWA）。**不需要每个人自己部署，也不分发桌面安装包、没有 APK**：更新只需重启服务端，用户刷新页面即可。

- 访问地址：**待域名生效后填在这里**（规划中 `https://everony.eu.org`），任何人点开就能注册

- 状态：**v2026.11.18.0.10.37**（服务端 + 界面 + OneBot 11 + 群聊 + Bot 广场 + 手机 PWA + 局域网手机直连 + 个性化外观 + 日志落盘）
- 架构：Fastify 5 + SQLite 单进程，一个进程同时托管接口与前端构建产物，见 [项目总览](docs/21-这个项目是怎么做出来的（总览）.md)
- 许可证：待定（默认 MIT，见 `docs/01-技术选型.md`）
- 参考实现：界面结构参考 [ChatPony](https://github.com/muyni233/ChatPony)，外观与代码均为独立实现

## 它解决什么

现有的即时通讯平台有两个问题：一是账号随时可能被平台封禁，二是你的数据、你的对话都不在你自己手里。Everony 把这两件事都还给运营者：

- **服务是运营者自己的**：一台机器、一个进程、一个网址，没有第三方平台能封你
- **数据是运营者自己的**：SQLite 单文件 + 上传目录，随时备份、随时搬走
- **用户不用装东西**：打开网址就能聊，手机添加到主屏幕即可，装不了软件的环境也能用
- **Bot 是一等公民**：运营者上架多个 Bot 到广场，游客没登录也能先逛，点开就聊，聊天记录按号码归档

## 快速了解设计要点

1. **号码是身份**：用户自选 8–11 位数字，站内唯一、永久不变；个人二维码里装的就是这个号码，扫码即可加好友。
2. **Bot 是正式账号**：有号码、有密码（scrypt）、有主人；主人可用「号码 + 密码」登进 Bot 身份，Bot 只能改自己的资料。
3. **注册有门禁**：默认「邮箱验证码 或 邀请码」，管理台可切换四档；没有「等站长审核」这一步。
4. **数据有期限、注销有冷静期**：消息默认保留 14 天自动清；注销账号 1–3 天后生效，期间可撤销。
5. **一个进程跑完**：Fastify 同时提供接口、上传与前端静态文件；SQLite 单文件就是全部数据。
