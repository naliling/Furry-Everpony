# Furry Everpony

一个**自托管、纯网页**的即时通讯服务。

运营者在一台常开的机器上跑一个后台服务，所有人——包括运营者自己——用浏览器打开网址就能用；手机用「添加到主屏幕」（PWA）。**不分发桌面安装包，也没有 APK**：更新只需重启服务端，用户刷新页面即可。

- 状态：**v2026.11.16.0.10.20**（服务端 + 界面 + OneBot 11 + 群聊 + Bot 广场 + 手机 PWA + 局域网手机直连 + 个性化外观 + 日志落盘）
- 底座：协议层用 [Matrix](https://matrix.org)（tuwunel），我们只写旁路服务与客户端，见 [Matrix 改造方案](docs/06-基于Matrix的改造方案.md)
- 许可证：待定（默认 MIT，见 `docs/01-技术选型.md`）
- 参考实现：界面结构参考 [ChatPony](https://github.com/muyni233/ChatPony)，外观与代码均为独立实现

## 它解决什么

现有的即时通讯平台有两个问题：一是账号随时可能被平台封禁，二是你的数据、你的对话都不在你自己手里。Everony 把这两件事都还给运营者：

- **服务是运营者自己的**：一台机器、一个进程、一个网址，没有第三方平台能封你
- **数据是运营者自己的**：SQLite 单文件 + 上传目录，随时备份、随时搬走
- **用户不用装东西**：打开网址就能聊，手机添加到主屏幕即可，装不了软件的环境也能用
- **Bot 是一等公民**：运营者上架多个 Bot 到广场，游客没登录也能先逛，点开就聊，聊天记录按号码归档

## 快速了解设计要点

1. **号码只在实例内唯一**，全局唯一的是 `@号码:实例域名`。这是 Matrix 的用户 ID 格式，由协议层强制，不是我们自己拼的字符串。两台机器上都有 `123456` 也不会串号。
2. **好友关系存的是全限定地址 + 对端公钥指纹**，消息带签名，冒充不了。
3. **Bot 必须由个人号创建**，人加 Bot 要主人审批，审批通过发邮件通知。
4. **不花一分钱能跑起来**：本机运行 + Tailscale 组网（免费版 100 设备）。
