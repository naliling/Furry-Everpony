# Furry Everpony

一个**自托管、去中心化**的即时通讯软件。

不是注册就能用的网站，而是**软件**：每个人下载到自己电脑上跑一个独立实例，每个实例有自己的用户和数据库。实例之间可以互相加好友、互相加 Bot。没有中心服务器，没有运营方，没有封号。

- 状态：**v2026.11.16.0.10.16**（服务端 + 界面 + OneBot 11 + 群聊 + Bot 广场 + 桌面打包 + 手机 PWA + 局域网手机直连 + 个性化外观 + 日志落盘 + 安卓 App（独立运行、本机服务端、原生通知））
- 底座：协议层用 [Matrix](https://matrix.org)（tuwunel），我们只写旁路服务与客户端，见 [Matrix 改造方案](docs/06-基于Matrix的改造方案.md)
- 许可证：待定（默认 MIT，见 `docs/01-技术选型.md`）
- 参考实现：界面结构参考 [ChatPony](https://github.com/muyni233/ChatPony)，外观与代码均为独立实现

## 它解决什么

现有的即时通讯软件有两个问题：一是账号随时可能被平台封禁，二是你的数据、你的 AI 模型都不在你自己手里。Furry Everpony 把这两件事都还给用户：

- **账号是你自己的**：跑在你自己电脑上，没人能封
- **模型是你自己的**：每个用户填自己的 API 地址和密钥，或者用免费的本地模型
- **数据是你自己的**：SQLite 单文件，随时备份、随时搬走
- **好友是跨实例的**：别人在他自己电脑上跑一份，你们照样能加好友聊天

## 快速了解设计要点

1. **号码只在实例内唯一**，全局唯一的是 `@号码:实例域名`。这是 Matrix 的用户 ID 格式，由协议层强制，不是我们自己拼的字符串。两台机器上都有 `123456` 也不会串号。
2. **好友关系存的是全限定地址 + 对端公钥指纹**，消息带签名，冒充不了。
3. **Bot 必须由个人号创建**，人加 Bot 要主人审批，审批通过发邮件通知。
4. **不花一分钱能跑起来**：本机运行 + Tailscale 组网（免费版 100 设备）。
