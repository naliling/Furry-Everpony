## 一、设计系统来源

### 评估过的 6 套

74 套里绝大多数是消费品牌、汽车、体育、金融官网，跟"桌面聊天工具"无关，不展开。真正值得比较的 6 套：

| 系统 | 优点 | 对本项目的问题 |
|---|---|---|
| **Linear** | 近黑 `#010102` 画布 + 四阶表面阶梯 + 1px 发丝线 + 单一强调色，产品 UI 即主角，信息密度高 | 纯黑偏冷，对"普通大众"有压迫感 |
| **xAI** | 最科幻：`#0a0a0a` + 白色描边胶囊 + 等宽眉标 | 极简到几乎没有亲和力，整站用会"太硬" |
| **Raycast** | 命令面板气质，操作工具感强 | 品牌红条纹必须换掉，换完所剩无几 |
| **Vercel** | 浅色、渐变、最大众友好 | 气质是部署平台，聊天界面要重新组织 |
| **Claude** | 暖白画布 `#faf9f5` + 衬线标题 + 珊瑚 `#cc785c`，最有人味的 AI 品牌 | 缺一套"工具"该有的结构 |
| **Slack** | 74 套里唯一为职场聊天而生的（茄紫 `#4a154b` + 胶囊 CTA） | 品牌色过重；且是营销页分析，不是应用 UI |

### 结论：不整套照搬，取三家拼装

| 层 | 来源 | 取什么 |
|---|---|---|
| **结构** | Linear | 四阶表面阶梯、1px 发丝线、无阴影、单一强调色、12px 圆角、负字距标题 |
| **色温** | Claude | 暖白画布 `#faf9f5`、墨黑文字 `#141413`、珊瑚强调 `#cc785c` |
| **科幻细节** | xAI | 等宽数字与眉标、胶囊描边按钮（仅用于设置页 / 关于页） |
| **不采用** | Raycast / Vercel / Slack | — |

一句话理由：聊天界面需要 Linear 的**密度和结构**，需要 Claude 的**亲和力**，需要 xAI 的一点**冷感**做"科幻"。三者分管不同层（结构 / 色温 / 点缀），所以不打架。

## 二、双主题

### FE-Dawn（默认主题，2026-11-13 用户拍板定稿）

暖白内容区 + 深色图标条，形成"冷结构、暖内容"的分层。

```css
:root[data-theme="dawn"] {
  /* 画布与表面（Linear 的四阶阶梯，色温换成 Claude 暖白） */
  --canvas:        #faf9f5;
  --surface-1:     #ffffff;
  --surface-2:     #f3f1ea;
  --surface-3:     #eae7de;
  --surface-4:     #e0dcd1;

  /* 发丝线 */
  --hairline:        #e3dfd5;
  --hairline-strong: #cdc7b9;

  /* 文字 */
  --ink:        #141413;
  --ink-muted:  #4a4843;
  --ink-subtle: #7d7a72;
  --ink-tertiary: #a8a49b;

  /* 强调（Claude 珊瑚） */
  --accent:       #cc785c;
  --accent-hover: #d98b72;
  --accent-focus: #b8674d;

  --rail:         #14161a;

  /* 语义 */
  --online: #3f9d8a;

  --warn:   #b8871f;
}
```

## 三、字体

| 用途 | 字体栈 |
|---|---|
| 展示标题（≥ 24px，仅登录页 / 关于页 / 空状态大标题） | `"Source Han Serif SC", "Noto Serif SC", "Songti SC", Georgia, serif` |
| 正文、界面文字 | `system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` |
| 号码、时间戳、眉标 | `ui-monospace, "Cascadia Mono", "SF Mono", Consolas, monospace` |

**中文不用衬线做正文**——Windows 自带的宋体在 14px 下会糊。衬线只用于大字号展示，正文一律无衬线。

| 用途 | 大小 | 字重 | 字距 |
|---|---|---|---|
| 展示标题 | 28–32px | 600 | -0.6px |
| 会话名 | 14px | 500 | 0 |
| 消息正文 | 14px | 400，行高 1.55 | 0 |
| 时间戳 | 11px | 400，等宽 | 0 |
| 号码 | 13px | 500，等宽，`tabular-nums` | 0 |
| 眉标（设置页分组标题） | 12px | 500，等宽，大写 | 0.6px |

## 四、布局

```
┌────┬──────────────┬────────────────────────────┐
│ 72 │   300px      │          flex:1            │
│ 图 │  会话列表     │         聊天区              │
│ 标 │              │                            │
│ 条 │  搜索框       │  顶栏：名字 + 在线状态       │
│    │  ─────────   │  ─────────────────────     │
│    │  会话项 × N   │  消息流（虚拟滚动）          │
│    │              │  ─────────────────────     │
│    │              │  输入框（多行，Enter 发送）  │
└────┴──────────────┴────────────────────────────┘
```

- 图标条 72px，5 个图标：消息、好友、Bot、设置、关于
- 会话列表 300px，可拖拽 240–400
- 聊天区最小 480px
- 窗口最小 900×600，小于则显示"窗口太小"

| 主按钮 | `--accent` 底 + 白字，圆角 8px，内边距 8×14，hover 用 `--accent-hover` |
| 次级按钮 | `--surface-1` 底 + `--ink` 字 + `--hairline` 边 |
| 胶囊按钮（xAI 风格，仅设置/关于页） | 透明底 + 1px 描边，圆角 9999px |
| 卡片 | `--surface-1` 底 + 1px `--hairline`，圆角 12px，内边距 24px |
| 分隔线 | 1px `--hairline`，**不用阴影** |

## 六、小马彩蛋

"小马"只作**灵感**，不出现任何具体角色形象（那是另一家公司的 IP，有商标风险）。

- **Logo**：一个圆环，环内偏右下是三个小圆 + 一个三角组成的抽象蹄印。单色，`--accent` 着色。
- **彩蛋开关**：设置页里一个不起眼的选项「暖色模式」，打开后把 `--accent` 换成小马暖紫 `#8b5cf6` 或暖粉 `#e88fa8`，其余不变。
- **加载动画**：三个小圆依次亮起，循环，2 秒一轮。低调，不喧宾夺主。
- **空状态**：可以放一句彩蛋文案，例如"这里还没有人说话"。

## 七、与参考实现的差异

ChatPony 只作**结构参考**（左列表 + 右聊天），外观必须明显不同：

| 维度 | ChatPony | Furry Everpony |
|---|---|---|
| 主色调 | 浅色 + 粉紫 | 暖白 + 珊瑚（Dawn）/ 近黑 + 紫蓝（Void） |
| 组件来源 | Radix UI + 圆角卡片 | 零组件库，纯 CSS 变量 + 1px 描边 |
| 导航 | 顶部/侧边文字导航 | 72px 纯图标条 |
| 气泡 | 对称圆角 | 对侧单角收尖（12px + 4px） |
| 阴影 | 大量卡片阴影 | 不用阴影，只用发丝线 |
| 字体 | 默认无衬线 | 展示衬线 + 正文无衬线 + 数字等宽 |
| 头像 | 方形/圆角方形 | 正圆 |

## 八、文案风格

- 全中文，用"你"不用"您"
- 不卖萌，不堆感叹号
- 错误提示 = 发生了什么 + 怎么办，例如"对方实例连不上，消息会在它上线后自动送达。"
- 禁止出现 QQ、腾讯、微信、小马角色名
