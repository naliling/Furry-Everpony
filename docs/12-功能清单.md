# 功能清单（现在已经能用的东西）

版本 v2026.11.13.0.8.2
这份是「**软件现在有什么**」，不是需求、不是待办。要加要改，照这份说话。

---

## 一、账号

- 用**号码 + 密码**注册登录（号码 5–12 位数字，不能 0 开头，注册时实时查重）
- 登录页只有两个输入框，看不到「服务器」「实例」这些词
- 头像可以上传（自动压成 256×256），还有昵称、签名
- 切换账号：设置里能切；登录过的账号都留着，随时切回来
- 可以**切换到自己的 Bot 身份**登录（看 Bot 眼里的世界）
- 设置里有「限制与注意事项」：删软件=数据没了、换电脑要拷数据、没有找回密码、号码不能改、token 是钥匙

## 二、好友

- 按号码搜人，弹出名片
- 发好友申请，对方同意或拒绝
- 「新朋友」入口带红点，显示有几条申请
- 给好友加备注名
- 删除好友
- 拉黑 / 解除拉黑

## 三、私聊

- 发文字、发图片
- 撤回自己 2 分钟内的消息
- 已读 / 未读（对方看到没）
- 置顶会话
- 搜消息（在这个会话里找关键词）
- 表情面板（26 个）
- Enter 发送，Shift+Enter 换行
- 未读红点数在会话列表上

## 四、群聊

- 建群：填群号和群名
- 用群号加群
- 群里发消息、看群成员
- 群主/管理员可改群名、写群公告
- 群主/管理员可踢人
- 退群（最后一个人退出，群自动消失）
- 群里 @ 人

## 五、Bot

- 创建 Bot：号码 + 昵称 + 简介，建完自动是你好友，直接能聊
- Bot 独立页：「我的 Bot」列表、在线状态、token 复制
- **Bot 广场**：搜公开 Bot，加好友、发消息
- 切换账号时能切到自己的 Bot

## 六、OneBot 11 协议端（给 AstrBot 这类程序用的）

- 连接地址：`ws://127.0.0.1:7788/onebot/v11/ws?access_token=<Bot的token>`
- 支持的事件：生命周期、心跳（30 秒）、私聊消息、群消息、好友添加
- 支持的操作：发私聊消息、发群消息、取登录账号、取好友列表、取群列表、取陌生人信息、取消息、撤回消息、发送状态
- 也就是说：AstrBot 把这里的 Bot 当成一个普通账号接上去，人格、记忆、插件都不用改

## 七、界面

- QQ 风格三栏：图标条 + 会话列表 + 聊天区
- 深色主题（默认）/ 浅色主题，设置里切
- 头像圆形
- 自绘标题栏：右上角 − □ × 三个按钮
- 窄屏（手机宽度）自动变成：列表占满 + 底部标签栏
- 建群、加好友、Bot 广场都在联系人页

## 八、数据和桌面

- 数据全在自己电脑：`%APPDATA%\furry-everpony\data\everpony.db`
- 不联网、不注册中心账号、不上传任何东西
- 桌面软件（Electron），能打包成 exe

## 九、测试

- 自动化测试 98 条，全过（接口 25 / OneBot 16 / 群和广场 32 / 综合功能 25）
