## A. 形态与分发

| # | 需求 | 状态 | 落地说明 |
|---|---|---|---|

## B. 账号与身份

| # | 需求 | 状态 | 落地说明 |

## H. 视觉与主题（2026-11-13 新增）

依据两份参考文件（74 套设计系统合并版 + Linear 详细分析），结论是**不整套照搬，取三家拼装**：结构 ← Linear，色温 ← Claude，科幻细节 ← xAI。详见 [04-视觉规范](04-视觉规范.md)。

| # | 需求 | 状态 | 落地说明 |
|---|---|---|---|
| H28 | 结构骨架用 Linear | ✅ | 四阶表面阶梯、1px 发丝线、无阴影、12px 圆角、负字距标题 |
| H29 | 色温用 Claude 暖白 | ✅ | 画布 `#faf9f5`、墨黑 `#141413`、珊瑚强调 `#cc785c` |
| H30 | 双主题 | ✅ | `FE-Dawn` 默认（暖白+珊瑚）、`FE-Void` 备选（近黑+紫蓝），v0.3 提供切换 |
| H31 | 科幻细节 | ✅ | 等宽数字与眉标、胶囊描边按钮，只用在设置页 / 关于页 |
| H32 | 小马彩蛋 | ✅ | 抽象蹄印 Logo、可切换的暖色强调、三点加载动画；**不出现任何具体角色形象**（IP 风险） |
| H33 | 强调色纪律 | ✅ | 只出现在四处：自己的气泡、未读红点、主按钮、聚焦环 |
| H34 | 不引 UI 组件库 | ✅ | 纯 CSS 变量，避免风格混入与"长得像别人" |
| H35 | 中文排版 | ✅ | 衬线只用于 ≥24px 展示标题，正文一律无衬线（Windows 宋体小字会糊） |
| H36 | 默认主题 | ✅ | 2026-11-13 用户拍板：默认 `FE-Dawn`（暖白 + 珊瑚）；`FE-Void` 留作 v0.3 可切换主题 |

## 明确不做（v0.1）

- 群聊、文件传输、语音视频、消息撤回、端到端加密、移动端 App
- 任何形式的中心化注册、授权码、付费门槛
- 任何自动重启 / 自动重连 / 看门狗机制
