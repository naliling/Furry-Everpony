# 18 · 产品方向变更：从「客户端软件 + 联邦」改成「纯网页 + 一台服务器」（2026-11-16）

> 状态：**待用户确认**。本文只记录方向与待定问题，不含实现细节；确认后才开工。

## 一、用户决定（原话见 docs/11 第十六节）

1. **不要软件形态了**：不再以桌面 exe / 安卓 App 作为主形态，改成**纯网页**——浏览器打开一个网址就能用。
2. **照 ChatPony 的使用方式**：一台服务器、所有人访问同一个站点、注册即用。用户理由：「而且还稳定」。
3. **不要自定义角色**：普通用户不建角色；Bot 由运营者（用户本人）创建并上架。
4. **用户会做好几个 Bot 放广场**：Bot 广场是核心入口，多个 Bot 并列展示。
5. **注册要有号码（可选）**：注册时可以选/分配一个数字号码，用途是「身份识别」，让 AI 记住这个号码说过什么（记忆绑定到号码）。
6. 旧的「联邦 / 邀请码 / 中继 / 跨实例」这一整套**不再是主路径**，最多作为将来可选项，当前不投入。

## 二、我方的技术判断（待用户认可）

- 网页形态天然解决「所有人互联」：所有人打开同一个网址 = 同一台服务器 = 同一个数据库，不需要穿透、不需要邀请码、不需要加好友。
- 稳定性来自「一个进程 + 一个 SQLite 文件」，只要那台机器在线就稳定；不依赖客户端版本、不依赖各家 NAT。
- 代价：所有数据集中在那台服务器上；机器挂了全都不能用；需要一台地址固定、常年开机的机器（这是唯一硬前提）。

## 三、域名与「长期稳定」的结论

- 用户看到的「后面长得一模一样」的网址，是免费托管平台的共享域名：`*.vercel.app`、`*.pages.dev`、`*.onrender.com`、`*.fly.dev`、`*.trycloudflare.com` 等。特点：白给、能立刻用、但不是自己的；免费层会休眠/限流/随时改政策，不适合长期。
- 长期稳定只有一条：**自己买一个域名**（约 10 美元/年，Cloudflare Registrar / Namecheap / 阿里云 / 腾讯云均可）+ 一台地址固定的机器（VPS 或家里有公网 IP 的机器）。
- 域名只解决「好记 + 能换机器不用改地址」，不解决「谁跑服务器」。服务器仍然是硬前提。
- 过渡方案（不推荐长期用）：DuckDNS 免费二级域名 + 端口转发（家宽无公网 IP 时无效）；Cloudflare 快速隧道（每次重启换地址）。
