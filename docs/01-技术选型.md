# 技术选型

> 版本：v2026.11.13.0.2.0
> 依据：[07-自写服务端方案](07-自写服务端方案.md)

## 一句话

**Electron 桌面应用 = 内嵌 Node 服务端（Fastify + SQLite）+ React 界面**，一个安装包，双击即用。

## 运行时与框架

| 层 | 选型 | 版本 | 理由 |
|---|---|---|---|
| 桌面外壳 | Electron | 33.x | 主进程原生 Node，服务端直接跑，无需二次打包 |
| 运行时 | Node.js | 22 LTS | Electron 33 内置 Node 20，开发环境统一 22 |
| 服务端框架 | Fastify | 5.x | 比 Express 快，内置 schema 校验，插件生态够用 |
| 数据库 | better-sqlite3 | 12.x | 同步 API，单文件，无服务进程，WAL 模式 |
| 实时通信 | ws | 8.x | 轻量，够用；不上 Socket.IO |
| 校验 | zod | 4.x | 所有外部输入（HTTP、WS、IPC）都过一遍 |
| 前端 | React + Vite | 19.x / 6.x | 函数组件 + hooks |
| 样式 | 原生 CSS 变量 | — | 不引 UI 框架，见 04-视觉规范 |
| 打包 | electron-builder | 26.x | NSIS 安装包，支持代码签名预留 |
| 测试 | node:test | 内置 | 零额外依赖 |

## 直接依赖预算

服务端 ≤ 8 个、前端 ≤ 4 个。**不引入**：Redis、ORM（手写 SQL）、Socket.IO、Express、Tailwind、UI 组件库、matrix-js-sdk（已放弃 Matrix 服务端）。

## 三端复用

同一套 React 界面，三个外壳：

| 端 | 外壳 | 服务端 |
|---|---|---|
| Windows / macOS / Linux | Electron 33 | 内嵌，完整实例 |
| Android / iOS | Capacitor 7 | 无，纯客户端连实例 |

移动端不打包服务端，原因见 [07-自写服务端方案](07-自写服务端方案.md) 第六节。

## 进程与端口

```
Electron 主进程
├── Fastify 监听 127.0.0.1:7788        ← HTTP API + 静态资源
├── ws 挂在同一端口 /ws                ← 实时消息
└── better-sqlite3 → %APPDATA%\FurryEverpony\data\everpony.db
```

端口被占用时自动向上找空闲端口，通过 IPC 告诉渲染进程，不写死。

## 目录

```
projects/furry-everpony/
├── electron/         主进程：窗口、托盘、服务端生命周期
├── server/           服务端：Fastify 路由、SQLite、联邦
├── web/              渲染进程：React
├── shared/           主进程与渲染进程共用的类型/常量
└── docs/
```
