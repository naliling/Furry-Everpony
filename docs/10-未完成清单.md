## 四、交付规矩（每个条目都要过一遍）

1. `node --check` 服务端文件（`.tools/node-v22.23.5-win-x64/node.exe --check server/index.js`）
2. 测试全跑，报 RAN / PASS / FAIL / ERR（`.tools/test-p1.mjs` 等）
3. `.tools/node-v22.23.5-win-x64/node.exe node_modules/vite/bin/vite.js build`（产物 `dist/web`）
4. 重启后台服务端：`powershell -NoProfile -ExecutionPolicy Bypass -File .tools/restart-server.ps1`（杀 7788 → 等端口释放 → `launch-server.mjs` 无窗口拉起）。**不再有安装目录、不再打包 exe/APK**，服务端直接跑项目里的 `server/index.js` 并托管 `dist/web`
5. `curl 127.0.0.1:7788/api/health` 版本号对得上；`Get-Process -Id <pid>` 的 `MainWindowHandle` 应为 0（无黑窗）
6. 版本号五处同步：package.json / server/index.js 的 `const VERSION` / AGENTS.md / README.md / CHANGELOG.md

## 五、后台服务端运维（2026-11-16 起）

- 启动：`.tools/launch-server.mjs`（spawn + detached + windowsHide，父进程立刻退出，服务端常驻且无窗口）
- 重启：`.tools/restart-server.ps1`
- 开机自启：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\EveronyServer.vbs`（调 `launch-server.mjs`）
- 环境变量：`.tools/server.env`（FE_DB / FE_PORT / FE_HOST / FE_LOG_DIR，均为绝对路径）
- 日志：`data/logs/app-YYYYMMDD.log`；数据：`data/everpony.db` + `data/uploads/`
- 访问：本机 `http://127.0.0.1:7788`，同 Wi-Fi `http://192.168.18.69:7788`
