# 数据模型

所有表都在单个 SQLite 文件 `data/everpony.db` 里。时间统一存 Unix 毫秒（INTEGER）。

## 核心概念

- **instance**：一个部署。本机有且只有一个"自身实例"，另有若干"已知远端实例"。
- **fqid**：全限定地址，格式 `实例指纹.号码`，例如 `a3f9c2d1.123456`。跨实例唯一。
- **number**：6–9 位数字，实例内唯一。

## 表结构

### instances —— 自身实例

```sql
CREATE TABLE instances (
  id            INTEGER PRIMARY KEY CHECK (id = 1),  -- 只允许一行
  fingerprint   TEXT NOT NULL UNIQUE,               -- 16 位十六进制，实例指纹
  name          TEXT NOT NULL,                      -- 实例名，如"娜莉灵的电脑"
  public_key    TEXT NOT NULL,                      -- Ed25519 公钥（base64）
  private_key   TEXT NOT NULL,                      -- Ed25519 私钥（AES-256-GCM 加密后 base64）
  created_at    INTEGER NOT NULL
);
```

### known_instances —— 已知的远端实例（TOFU 首次信任）

```sql
CREATE TABLE known_instances (
  fingerprint   TEXT PRIMARY KEY,
  name          TEXT NOT NULL DEFAULT '',
  public_key    TEXT NOT NULL,
  last_address  TEXT,                               -- 最后成功连接的 host:port
  trust         TEXT NOT NULL DEFAULT 'tofu',       -- tofu | trusted | blocked
  first_seen    INTEGER NOT NULL,
  last_seen     INTEGER
);
```

### accounts —— 账号（个人号 + Bot 号）

```sql
CREATE TABLE accounts (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  instance_fp   TEXT NOT NULL,                      -- 本机 = 自身实例指纹
  number        TEXT NOT NULL,                      -- 6–9 位数字
  fqid          TEXT NOT NULL UNIQUE,               -- instance_fp || '.' || number
  type          TEXT NOT NULL CHECK (type IN ('user','bot')),
  email         TEXT UNIQUE,                        -- 仅 user，bot 为 NULL
  password_hash TEXT,                               -- 仅 user，argon2id
  display_name  TEXT NOT NULL,
  avatar_path   TEXT,                               -- data/avatars/xxx.png
  bio           TEXT NOT NULL DEFAULT '',
  owner_id      INTEGER REFERENCES accounts(id),    -- 仅 bot：创建者
  status        TEXT NOT NULL DEFAULT 'active',     -- active | disabled
  created_at    INTEGER NOT NULL
);
CREATE UNIQUE INDEX idx_accounts_number ON accounts(instance_fp, number);
```

**约束**：`type='bot'` 时 `owner_id` 必须非空且指向一个 `type='user'` 的账号；`type='user'` 时 `owner_id` 必须为 NULL。由应用层在事务内保证。

### friend_requests —— 好友申请

```sql
CREATE TABLE friend_requests (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  from_fqid   TEXT NOT NULL,
  to_fqid     TEXT NOT NULL,
  message     TEXT NOT NULL DEFAULT '',
  status      TEXT NOT NULL DEFAULT 'pending',      -- pending | accepted | rejected | cancelled
  created_at  INTEGER NOT NULL,
  decided_at  INTEGER
);
CREATE INDEX idx_fr_to ON friend_requests(to_fqid, status);
```

### friendships —— 好友关系（无向，存两份以防漏查）

```sql
CREATE TABLE friendships (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  owner_fqid TEXT NOT NULL,                         -- 关系归属方
  peer_fqid  TEXT NOT NULL,                         -- 对方
  peer_inst  TEXT NOT NULL,                         -- 对方实例指纹
  peer_key   TEXT NOT NULL,                         -- 对方实例公钥指纹（防冒充）
  created_at INTEGER NOT NULL,
  UNIQUE(owner_fqid, peer_fqid)
);
```

同意好友时写两条（A→B、B→A），在同一个事务里。

### blocks —— 黑名单

```sql
CREATE TABLE blocks (
  owner_fqid   TEXT NOT NULL,
  blocked_fqid TEXT NOT NULL,
  created_at   INTEGER NOT NULL,
  PRIMARY KEY (owner_fqid, blocked_fqid)
);
```

### conversations / messages —— 会话与消息

```sql
CREATE TABLE conversations (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  kind       TEXT NOT NULL DEFAULT 'direct',        -- direct | group(v0.2)
  title      TEXT,                                  -- group 用
  created_at INTEGER NOT NULL
);

CREATE TABLE conversation_members (
  conversation_id INTEGER NOT NULL REFERENCES conversations(id),
  fqid            TEXT NOT NULL,
  joined_at       INTEGER NOT NULL,
  last_read_at    INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY (conversation_id, fqid)
);

CREATE TABLE messages (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  conversation_id INTEGER NOT NULL REFERENCES conversations(id),
  sender_fqid     TEXT NOT NULL,
  body            TEXT NOT NULL,
  sig             TEXT,                             -- 跨实例消息的 Ed25519 签名
  created_at      INTEGER NOT NULL,
  delivered_at    INTEGER,
  read_at         INTEGER
);
CREATE INDEX idx_msg_conv ON messages(conversation_id, id);
```

### bot_configs —— Bot 的模型配置（BYOK）

```sql
CREATE TABLE bot_configs (
  account_id   INTEGER PRIMARY KEY REFERENCES accounts(id),
  base_url     TEXT NOT NULL,                       -- OpenAI 兼容地址
  api_key      TEXT NOT NULL,                       -- AES-256-GCM 加密
  model        TEXT NOT NULL,
  temperature  REAL NOT NULL DEFAULT 0.8,
  max_tokens   INTEGER NOT NULL DEFAULT 1024,
  system_prompt TEXT NOT NULL DEFAULT '',
  enabled      INTEGER NOT NULL DEFAULT 1,
  updated_at   INTEGER NOT NULL
);
```

### bot_access —— Bot 的"熟人"白名单

```sql
CREATE TABLE bot_access (
  bot_id     INTEGER NOT NULL REFERENCES accounts(id),
  fqid       TEXT NOT NULL,                         -- 被允许的对方
  peer_key   TEXT NOT NULL,                         -- 对方实例公钥指纹
  granted_at INTEGER NOT NULL,
  PRIMARY KEY (bot_id, fqid)
);
```

Bot 收到消息时校验：`sender_fqid` 在 `bot_access` 里 **且** 签名用的公钥指纹匹配 `peer_key`，两者都对才回。这就是"识别熟人"。

### presence —— 在线状态

```sql
CREATE TABLE presence (
  fqid          TEXT PRIMARY KEY,
  instance_fp   TEXT NOT NULL,
  online        INTEGER NOT NULL DEFAULT 0,
  last_heartbeat INTEGER NOT NULL,
  last_seen     INTEGER NOT NULL
);
```

心跳 30 秒；`now - last_heartbeat > 90000` 判离线。

### mail_queue —— 待发邮件

```sql
CREATE TABLE mail_queue (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  to_email   TEXT NOT NULL,
  subject    TEXT NOT NULL,
  body       TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  sent_at    INTEGER,
  error      TEXT
);
```

用于 Bot 被添加时的主人通知、注册验证。失败不阻塞主流程，后台每 60 秒重试一次，最多 5 次。

### outbox —— 跨实例待投递消息

```sql
CREATE TABLE outbox (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  to_instance  TEXT NOT NULL,                       -- 目标实例指纹
  address      TEXT NOT NULL,                       -- host:port
  payload      TEXT NOT NULL,                       -- JSON
  attempts     INTEGER NOT NULL DEFAULT 0,
  next_try_at  INTEGER NOT NULL,
  created_at   INTEGER NOT NULL,
  done_at      INTEGER
);
```

对端不可达时消息进这里，按退避重试（10s → 30s → 2min → 10min → 1h，最多 24 小时）。**注意：这是消息重试，不是进程重启，不违反"不要看门狗"的规矩。**

### settings —— 键值配置

```sql
CREATE TABLE settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
```

初始键：`instance.name`、`smtp.host`、`smtp.port`、`smtp.user`、`smtp.pass`、`smtp.from`、`register.email_verify`、`register.enabled`、`limit.msg_per_min`。

## 迁移

`server/migrations/` 下按 `NNN_描述.sql` 命名，启动时读 `PRAGMA user_version`，依次执行未应用的脚本并在事务里更新版本号。
