## 1. 视觉规范（「更科技化更好看」的落地口径）

基座：深空蓝黑，玻璃拟态面板 + 霓虹青紫点缀，克制发光。

```css

--bg-2: #101a2b;        /* 卡片/输入框 */
--glass: rgba(20, 32, 52, .55);
--line: rgba(120, 180, 255, .12);
--text-0: #e8f1ff;
--text-1: #9fb2cf;
--text-2: #6b7f9e;
--cyan: #22d3ee;
--violet: #a855f7;
--blue: #3b82f6;
--ok: #34d399;
--warn: #fbbf24;
--danger: #fb7185;
--accent-grad: linear-gradient(135deg, #22d3ee 0%, #3b82f6 45%, #a855f7 100%);
```

- 背景：`--bg-0` + 两层细节（径向光晕 1 个大范围青紫、1 个左上蓝光；4% 透明度 32px 网格），固定不动，`pointer-events:none`。
- 面板：`background: var(--glass); backdrop-filter: blur(18px); border: 1px solid var(--line); border-radius: 16px`。
- 焦点态：`outline: 2px solid rgba(34,211,238,.55); outline-offset: 2px`（键盘可达）。
- 动效：`transition: 160ms cubic-bezier(.2,.8,.2,1)`；列表进入用 8px 上移淡入；**不**做夸张粒子/滚动动画。
- 图标：内联 SVG，stroke 1.7，尺寸 18/20/22 三档；不许引入图标库或外部字体。
- 头像：圆形，渐变底 + 首字；在线状态用右下角小圆点（绿/黄/红/灰）。
- 字体：`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`；数字与号码用 `font-variant-numeric: tabular-nums`。
- 三套主题（CSS 变量切换，存 localStorage `fe_theme`）：`deep`（默认深空）、`violet`（暗夜紫）、`light`（晨雾浅色，需保证对比度）。切换入口在设置页。
- 字号三档（localStorage `fe_font`）：小 14px / 中 15px / 大 16px，作用在 `:root { font-size }`。

## 2. 布局与断点

- ≥ 1080px：三栏 = 频道栏 64px + 列表栏 `clamp(240px, 22%, 288px)` + 聊天区自适应。列表栏占比控制在 22% 左右（对齐主流 IM，别做 24%+ 的宽侧栏）。
- 760–1080px：两栏 = 频道栏 64px + 列表 240–260px + 聊天区；聊天区上层工具栏收窄。
- < 760px（手机）：单页栈 = 底部四个 tab（消息/联系人/发现/我的），点进会话为推入页（左滑返回、系统返回手势、顶部返回按钮）；输入区避让键盘，`100dvh` + `env(safe-area-inset-*)`；触摸目标 ≥ 40px；长按 = 右键菜单。
- 桌面端：保留 `window.feWin` 窗口控制按钮（无则隐藏）；右键菜单；快捷键：Ctrl+F 搜索、Esc 关闭浮层、Ctrl+N 新建会话、↑ 编辑上一条、Alt+↑/↓ 切换会话。
- 移动端：隐藏窗口控制；不显示 hover 态；滚动惯性；顶部状态条颜色 = 主题色。

## 3. 接口契约（后端由 Lead 实现，前端照此调用）

所有需要登录的接口都带 `Authorization: Bearer <token>`；错误统一 `{ error: "中文提示" }`，状态码 400/401/403/404/409。

### 3.1 消息发送（三个入口同步扩展）

- `POST /api/conversations/:id/messages`
- `POST /api/messages`（按号码；body 里多一个 `to`）
- `POST /api/groups/:number/messages`

请求体：
```json
{
  "body": "文本或 data:image/... 或 /uploads/xxx 或转发摘要",
  "kind": "text | image | file | voice | forward | merge",
  "replyTo": 123,
  "mentionAll": false,
  "meta": { "name": "a.pdf", "size": 12345, "duration": 8, "title": "聊天记录", "count": 2, "items": [] }
}
```
- `kind=text` 时 body 1–4000 字；`kind=image` body 为 data URL（≤2.5MB 字符串）或 `/uploads/...`；`kind=file/voice` 的 body 是 `/uploads/...` 地址，展示信息在 `meta`。
- `replyTo` 必须是同会话内的消息 id，否则 400。
- `mentionAll=true` 只有群主/管理员可用，否则 403「只有群主和管理员能 @全体成员」。
- 群全员禁言/成员被禁言时发消息 → 403（群主/管理员不受全员禁言限制）。
- 返回：`{ ok, message: { id, body, kind, meta, reply, reactions: [], created_at } }`。

消息对象（GET 列表/发送返回统一）：
```json
{
  "id": 1, "mine": true, "body": "...", "kind": "text", "recalled": false,
  "created_at": 1763000000000,
  "meta": { },
  "reply": { "id": 9, "number": "10001", "nickname": "小马", "body": "原话", "kind": "text" },
  "reactions": [ { "emoji": "👍", "count": 2, "mine": true } ],
  "sender": { "number": "10002", "nickname": "群名片优先", "avatar": "" }
}
```
- `GET /api/conversations/:id/messages?after=<id>` 额外返回 `typing: [{ number, nickname }]`（6 秒内正在输入的人，不含自己）。

### 3.2 消息操作

| 接口 | 说明 |
|---|---|
| `POST /api/messages/:id/reactions` `{emoji}` | 切换表情回应，返回 `{ok, reactions}` |
| `POST /api/messages/:id/delete` | 仅自己删除（对方仍可见），返回 `{ok}` |
| `POST /api/messages/:id/favorite` / `DELETE` | 收藏/取消收藏，返回 `{ok}` |
| `GET /api/favorites` | `{favorites:[{saved_at, message, conversation:{kind:"dm",peer:{number,nickname,avatar}} 或 {kind:"group",group:{number,name}}}]}` |
| `POST /api/messages/:id/forward` `{conversationId}` | 单条转发 |
| `POST /api/conversations/:id/forward-merge` `{messageIds:[...], conversationId}` | 合并转发，最多 50 条；生成 kind=merge 的消息，meta 为 `{title:"聊天记录",count,items:[{number,nickname,kind,body,created_at}]}` 快照 |
| `POST /api/conversations/:id/typing` `{typing:true}` | 上报正在输入（前端节流 2s 一次） |
| `POST /api/messages/:id/recall` | 已存在：2 分钟内本人可撤回 |

### 3.3 会话

- `GET /api/conversations` 每条：`{id,kind,peer,group,last:{id,body,kind,preview,mine,created_at}|null,unread,pinned,muted,peerRead}`；`peer` 含 `online/status/last_seen`；置顶优先、再按 last.id 降序。
- `POST /api/conversations/:id/mute` `{muted:boolean}`。
- 置顶/已读/搜索沿用现有接口。
- 草稿：前端 localStorage（`fe_draft_<convId>`），不发后端。

### 3.4 上传（图片/文件/语音）

- `POST /api/upload?name=<文件名>`，Content-Type: `application/octet-stream`，原始二进制，≤ 25MB。
- 返回 `{ ok, url: "/uploads/2026...-abc.pdf", name, size, mime }`。
- 前端得到 url 后，再用 kind=file/voice 发消息；图片也可用上传（推荐，替代 data URL）。
- `/uploads/*` 由服务端静态提供（生产环境由 Electron 内嵌 Fastify 托管）。

### 3.5 好友与联系人

- `GET /api/friends` 每条增加：`remark`, `special`, `group_id`, `online`, `status`, `last_seen`。
- 好友分组：
  - `GET /api/friend-groups` → `{groups:[{id,name,sort_order,count}]}`（无 ungrouped 字段）
  - `POST /api/friend-groups` `{name}`；`PATCH /api/friend-groups/:id` `{name}`；`DELETE /api/friend-groups/:id`
  - 改分组/特别关心/备注统一走 `PATCH /api/friends/:number` `{groupId?: 3|null, special?: boolean, remark?: string}`（没有单独 group/special 路由）
- 在线状态：`PATCH /api/me` `{status:"online|away|busy|invisible"}`（invisible 时别人看到 offline）。
- 好友申请（含 Bot 审批）：
  - `GET /api/friends/requests` → `{incoming, outgoing, botIncoming}`；`botIncoming` 是「别人申请加我的 Bot」的条目，每项 `{id, from:{number,nickname,avatar}, bot:{number,nickname}, message, created_at}`。
  - `POST /api/friends/accept` `{number, bot?}`：`bot` 填我的 Bot 号码时表示替 Bot 同意；不填 = 同意发给我的申请。
  - `POST /api/friends/reject` `{number, bot?}` 同理。
  - 给 Bot 发申请时，Bot 不会自动通过；只有主人能通过（R41）。

### 3.6 群

- `GET /api/groups` 每条增加：`announcement`, `announcement_updated_at`, `mute_all`, `members`（成员数）, `pending`（待处理邀请数）。
- 邀请/申请：
  - `POST /api/groups/:number/invite` `{number}` → 生成待同意邀请，返回 `{ok, pending:true}`（已是成员 409）。
  - `GET /api/group-requests` → `{incoming:[{id,created_at,group_id,number,name,from_number,from_nickname,from_avatar,to_number,to_nickname}], outgoing:[...]}`（扁平字段，非嵌套 group/from）
  - `POST /api/group-requests/:id/accept` / `reject`（只有被邀请人可操作）。
  - 群号直接加入 `POST /api/groups/:number/join` 保留（开放群）。
- 成员管理：
  - `GET /api/groups/:number/members` → 每项 `{number, nickname(展示名=群名片优先), group_nickname, bio, avatar, type, status, role, online, last_seen, mute_until, joined_at}`
  - 设/撤管理员：`POST /api/groups/:number/admin` `{number, admin:boolean}` 仅群主。
  - 禁言成员：`POST /api/groups/:number/mute` `{number, minutes:0-43200}` 群主/管理员；不能禁言群主；管理员只有群主能禁。
  - `PATCH /api/groups/:number/me` `{nickname}` 改自己的群名片。
  - `POST /api/groups/:number/mute-all` `{muteAll:boolean}` 仅群主/管理员。
  - `PATCH /api/groups/:number` 已有：群名/公告；公告更新时前端弹确认。
  - `POST /api/groups/:number/announcement/read` 标记公告已读。
- 群文件：
  - `POST /api/groups/:number/files` `{name,url,size}`（url 来自 /api/upload）
  - `GET /api/groups/:number/files` → `{files:[{id,name,url,size,created_at,uploader_number,uploader_nickname}]}`（扁平）
  - `DELETE /api/groups/:number/files/:id`（上传者/管理员/群主）

### 3.7 通知中心

- `GET /api/notifications` → `{count, items:[{type:"friend_request"|"bot_request"|"group_invite"|"announcement", requestId?, created_at, ...}]}`，按 created_at 倒序；friend_request 带 from:{number,nickname,avatar,type}，bot_request 带 from+bot，group_invite/announcement 带 group:{number,name}（announcement 另有 announcement 正文），用于频道栏铃铛红点。
- 操作后（同意/拒绝/读公告）条目自然消失，无需已读标记接口。

### 3.8 账号与实例

- `PATCH /api/me` 扩展：`nickname`, `bio`, `avatar`, `status`。
- `POST /api/me/password` `{oldPassword,newPassword}`。
- `GET /api/server-info` → `{version, port, host, boundToLan, lanUrls:string[], webReady}`（设置页显示手机访问地址；仅当 boundToLan 才可用，lanUrls 已是完整 URL 字符串数组）。
- `GET /api/bots/:number/stats` 已有（ranking + total），前端补「发言排行」块。
