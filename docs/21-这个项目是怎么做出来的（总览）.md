## 1. 起因

### 1.1 原来的做法

最早的形态是「把自己的 Bot 接进别人的聊天软件」：用第三方协议端（NapCat 这一类）把 Bot 挂上去，项目里也写过 OneBot 11 的接入层。

### 1.2 撞到的墙

- **协议端随时会失效**。它不是官方接口，说停就停；一停，Bot 就整个不存在了。
- **账号不属于自己**。号码是别人的、好友关系是别人的、聊天记录是别人的，平台一句话就能让这个 Bot 从世界上消失。
- **别人的 Bot 也一样**。不只是我这一个 Bot 的问题，是这个做法本身的问题。

### 1.3 于是改成

**自己做一个网页。** 一台常开的机器跑服务，所有人（包括站长自己）用浏览器打开网址就能用：

- Bot 有自己真实的号码和密码，能登录，能改自己的资料——它是这个站里的一个正式账号，不是挂在别人身上的插件。
- 数据只留在自己那台机器上，不经过任何第三方。
- 别人也能来用，别人的 Bot 也能挂进来，站长是「开站的人」，不是「借地方的人」。

这条路线的取舍写在 `docs/18-产品方向变更（纯网页）.md` 与 `docs/19-网页版需求定稿.md`。

## 2. 现在它是什么样子

### 2.1 形态

| 项目 | 现在 |
|---|---|
| 分发方式 | **只发网页**，不再有桌面安装包、不再有手机安装包 |
| 打开方式 | 电脑：浏览器收藏 / 钉到桌面；手机：浏览器「添加到主屏幕」（PWA） |
| 部署规模 | **一台机器、一个进程、一个 SQLite 文件** |
| 域名 | 可选。内网用 `http://IP:7788`，公网建议配域名 + 隧道/反代 |
| 数据位置 | 全部在本机 `data/everpony.db` 与 `data/uploads/` |

### 2.2 三种身份

| 身份 | 是什么 | 能做什么 |
|---|---|---|
| **站长** | 开站的人（空库第一个注册的账号自动成为站长） | 管账号、删号、封禁、改注册门禁、配发信、看登录记录、生成邀请码、上架/下架 Bot |
| **普通人** | 自己注册进来的用户 | 加好友、私聊、建群、逛广场、跟 Bot 聊天、改自己的资料与外观 |
| **Bot** | 由某个人创建、归那个人管的账号 | 有号码、有密码，**主人可以用「号码 + 密码」登进 Bot 的身份**；登录后只有「消息」和「我的」两个入口 |

### 2.3 五个界面分区（电脑左侧图标栏 / 手机底部五个 tab）

| 分区 | 作用 |
|---|---|
| **广场** | 首页。没登录就能看见站里有哪些公开 Bot，挑一个直接开聊 |
| **消息** | 会话列表 + 聊天窗口（私聊、群聊、Bot 对话） |
| **联系人** | 好友、分组、新朋友申请、群聊入口 |
| **我的** | 个人资料、外观、聊天背景、账号与安全、我的邀请码、关于、危险操作 |
| **管理** | 只有站长看得见。账号 / 站点 / 审核 / 登录记录 / 防护 / Bot / 消息 七个分区 |

## 3. 技术骨架

### 3.1 选型

| 层 | 用了什么 | 为什么 |
|---|---|---|
| 运行时 | Node.js 22（项目自带 `.tools/node-v22.23.5-win-x64/`） | 单进程就能跑完整个站；自带 `node:sqlite`，不用装数据库 |
| 数据库 | SQLite 单文件（`data/everpony.db`） | 零运维，复制一个文件就是全部数据 |
| 后端框架 | Fastify 5 | 轻、快，路由和 schema 校验直接写在路由上 |
| 参数校验 | zod | 所有外部输入都过一遍，非法直接 400 |
| 前端 | React 19 + Vite 6 | 函数组件 + hooks；**不引任何 UI 框架**，样式全是 CSS 变量 |
| 实时 | WebSocket（`ws`）+ 轮询退避 | 在线消息走 WS，断线时退回轮询（4s→8s→15s 退避） |
| 发信 | 自写 SMTP 客户端 `server/mail.js` | 不引第三方库，465 / 587 / 25 都支持 |
| 打包 | 无 | 服务端直接跑源码，前端 `vite build` 出静态文件 |

**零中心依赖**：所有功能单实例可完整运行，不连任何作者的服务器。

### 3.2 进程与目录

```
一个 node 进程
├── Fastify HTTP 服务（默认 7788）
│   ├── /api/*      后端接口（133 个）
│   ├── /uploads/*  上传的图片
│   └── /*          前端构建产物 dist/web（同一进程托管）
├── WebSocket      实时消息
└── 每小时清理任务   过期注销真删、超期消息清理
```

```
projects/furry-everpony/
├── server/            后端
│   ├── index.js       主服务：133 个接口、鉴权、限流、清理任务（约 4500 行）
│   ├── db.js          建表与迁移（25 张表）
│   ├── mail.js        零依赖 SMTP 客户端
│   ├── onebot.js      OneBot 11 接入（给外部 Bot 程序用）
│   ├── ai.js          Bot 的模型调用（BYOK，自带 key）
│   ├── log.js         分级日志，写 data/logs/
│   └── scripts/       14 个测试脚本
├── web/src/           前端
│   ├── App.jsx        启动、路由、登录态
│   ├── views/         页面（Auth / Shell / Settings / Admin / chat / contacts / discover / plaza / shared）
│   ├── ui/            内联图标、基础组件、二维码
│   ├── lib/           接口封装、格式化、聊天背景
│   └── *.css          五层样式（styles / layout / pages / chat / effects + theme）
├── docs/              设计与需求文档（00–21）
├── .tools/            运维与测试脚本（启动、看门狗、隧道、截图、测试）
└── data/              运行时数据（gitignore）
```

### 3.3 一条消息的完整路径

```
你按下回车
  → Composer 组包 → POST /api/messages（带 Bearer token）
  → 鉴权（auth：token 有效 + 账号未封禁 + 未到期注销）
  → 限流（每 IP 每分钟 900 次）
  → zod 校验 → 事务写入 messages 表
  → 通过 WebSocket 推给会话里其他在线成员
  → 对方 ChatPanel 收到推送 → 追加到列表 → 未读 +1
  → 会话列表按最后一条消息重排
```

## 4. 数据长什么样

25 张表，按用途分五组（定义在 `server/db.js`）：

| 组 | 表 | 作用 |
|---|---|---|
| **账号** | `accounts` `sessions` `login_logs` `ip_bans` | 账号本体（含 `type`=user/bot、`is_admin`、`banned`、`deleted_at` 冷静期）、登录令牌、登录流水、IP 黑名单 |
| **社交** | `friend_requests` `friendships` `blocks` `friend_groups` | 好友申请、好友关系（双向）、拉黑、好友分组 |
| **会话** | `conversations` `conversation_members` `messages` `message_reactions` `message_deletions` `favorites` | 会话、成员、消息、表态、撤回记录、收藏 |
| **群聊** | `groups` `group_members` `group_requests` `group_files` | 群、群成员、入群申请、群文件 |
| **Bot 与站务** | `bot_links` `bot_models` `instance_meta` `federation_outbox` `settings` `invite_codes` `email_codes` | Bot 与 OneBot 绑定、Bot 用的模型配置、站点元信息、待发队列、键值设置、邀请码、邮箱验证码 |

设计要点：

- **号码是身份**。`accounts.number` 是用户自选的 8–11 位数字（不能 0 开头），站内唯一，永久不变；二维码里装的就是这个号码。
- **Bot 就是一行账号**。`type='bot'`，有 `owner_id`（主人）、`password_hash`（能登录）、`is_public`（是否上广场）。
- **注销不立刻删**。`deleted_at` 存「计划删除时间」，到期由清理任务真删，期间可以撤销。
- **所有写操作走事务**，避免半条数据。

## 5. 服务端怎么组织

`server/index.js` 一个文件里按功能分区，133 个接口。主要几组：

| 分组 | 代表接口 | 说明 |
|---|---|---|
| 健康与站点 | `GET /api/health` `GET /api/site` | 版本、站点名、注册门禁、是否配了发信、数据保留天数 |
| 注册登录 | `POST /api/register` `POST /api/login` `GET /api/captcha` `POST /api/email-code` | 图形验证码 + 邮箱码 / 邀请码门禁；登录记录 IP 与设备 |
| 我的 | `GET /api/me` `PATCH /api/me` `GET /api/me/sessions` `GET /api/me/invite` `POST /api/me/delete` | 资料、登录设备、自己的邀请码、注销申请与撤销 |
| 找人加好友 | `GET /api/search/users` `POST /api/friends/request` | 按号码 / 昵称 / 标签联想；加好友走申请制 |
| 会话消息 | `GET /api/conversations` `POST /api/messages` `POST /api/dm` `GET /api/messages/search` | 私聊、群聊统一进会话表；支持搜索、表态、撤回、收藏 |
| 群聊 | `POST /api/groups` `POST /api/groups/:number/join` `PATCH /api/groups/:number` | 建群、入群、群公告、群文件 |
| Bot | `POST /api/bots` `PATCH /api/bots/:number` `GET /api/bots/public` | 建 Bot（带密码）、改资料、公开 Bot 列表（广场数据源） |
| OneBot 11 | `/onebot/*` | 外部 Bot 程序（NapCat 一类）用 token 接入 |
| 管理台 | `GET /api/admin/overview` `/api/admin/accounts` `/api/admin/site` `/api/admin/invites` `/api/admin/logins` `/api/admin/ip-bans` | 统计、账号封禁与删除、站点设置、邀请码、登录流水、IP 封禁 |
| 上传 | `POST /api/upload` `/uploads/*` | 图片，最大 25 MB |

安全与稳定：

- **密码 scrypt**（`scrypt$salt$key` + `timingSafeEqual`），不存明文、不存裸哈希。
- **限流**：全局每 IP 每分钟 900 次；登录失败同 IP 10 分钟 20 次、同账号 5 次即锁；注册同 IP 10 分钟 20 次；发验证码 IP 5 次 / 同邮箱 3 次。
- **IP 封禁**在 `onRequest` 阶段直接 403，并顺手删掉该 IP 的全部会话。
- `trustProxy` 打开，经隧道/反代时拿到真实访客 IP。
- **每小时清理**：到期的注销账号真删；超过保留天数的消息与无人引用的图片删掉。

## 6. 前端怎么组织

### 6.1 视图树

```
App.jsx（启动：读 token → 拉 /api/me → 决定进登录页还是主界面）
├── Auth.jsx        登录 / 注册（号码或邮箱、图形验证码、邮箱码或邀请码）
└── Shell.jsx       主界面外壳：左侧图标栏 / 手机底部 tab
    ├── PlazaPage.jsx      未登录也能看的公开 Bot 广场
    ├── DiscoverTab.jsx    登录后的广场（公开 Bot + 我的 Bot + 站点信息条）
    ├── ChatTab.jsx        会话列表
    │   └── ChatPanel.jsx  聊天窗口
    │       ├── Message.jsx     单条消息（文本 / 图片 / 语音 / 引用 / 表态）
    │       ├── Composer.jsx    输入区（发图、语音、@、发送方式）
    │       ├── ChatBgPanel.jsx 聊天背景（只存在浏览器本地）
    │       └── GroupInfo.jsx   群资料
    ├── ContactsTab.jsx    好友与群
    ├── Settings.jsx       我的
    └── admin/AdminPage.jsx 管理台
```

共用弹窗都在 `views/shared/Dialogs.jsx`（加好友、建群、加入群、转发、合并查看、公告、群邀请、全局搜索）。

### 6.2 样式分层

| 文件 | 管什么 |
|---|---|
| `theme.css` | CSS 变量：颜色、间距、圆角、阴影、字号，以及主题 |
| `styles.css` | 全局基础：按钮、输入框、卡片、表单 |
| `layout.css` | 外壳：左侧图标栏、手机底部 tab、内容区 |
| `pages.css` | 各页面与弹窗（最大的一层） |
| `chat.css` | 聊天窗口、消息气泡、输入区 |
| `effects.css` | 动效、聊天背景、氛围光 |

**不引 UI 框架**，所有图标是内联 SVG（`ui/icons.jsx`）。

### 6.3 电脑与手机怎么分别照顾

- 同一套组件，靠 `useIsMobile()` 和媒体查询分叉。
- 电脑：左侧 64px 图标栏 + 内容区，广场三列铺满，设置页两栏卡片。
- 手机：底部五个 tab，广场单列，弹窗改成底部抽屉，输入区贴底且避开安全区。

## 7. 六个关键机制

### 7.1 注册门禁（不让随便一个人就能进来）

管理台「站点」分区四种门禁：

| 门禁 | 行为 |
|---|---|
| 邮箱码或邀请码（默认） | 配了发信就发 6 位验证码；没配就只认邀请码 |
| 只认邀请码 | 必须填有效邀请码 |
| 只认邮箱码 | 必须填自己邮箱收到的验证码 |
| 都不要 | 谁都能注册（不推荐） |

**没有「等站长审核」这一步**——注册完直接能用。邀请码可设「能用几次」「多少天过期」。

### 7.2 号码找人

`GET /api/search/users?q=` 按号码 / 昵称 / 标签模糊匹配，号码精确命中排最前，排除自己、被封禁的、注销中的。加好友弹窗是「边打边找」：停手 260ms 才发请求。

### 7.3 个人二维码

二维码内容就是**自己的号码**，永久不变、换设备不变、换浏览器不变。扫码方拿到号码直接发好友申请，不需要两边在同一网络。

### 7.4 数据限期

默认 **14 天**（管理台可改，0 = 永久）。每小时清理一次超期消息与没人引用的图片，给设备省空间。

### 7.5 注销冷静期

`POST /api/me/delete` 输入密码 + 选 1~3 天 → 账号进入待删状态 → 期间登录能看到生效时间、可以撤销 → 到期由清理任务真删（消息、会话、好友关系一起删）。唯一站长不能注销自己。

### 7.6 Bot 的身份

- 建 Bot 时设密码（≥8），存的是 scrypt 哈希。
- 主人用「Bot 的号码 + 密码」就能登录进 Bot 的身份。
- Bot 登录后只有「消息」和「我的」两个入口，能改自己的资料与密码，不会多出加好友、建群、管理入口。
- 想接外部程序（NapCat 一类）时，走 OneBot 11 接入：`/onebot/*` + 独立 `access_token`。

## 8. 怎么把它跑起来

### 8.1 开发

```bash
# 后端（默认 7788）
node server/index.js

# 前端热更新（Vite）
npx vite

# 构建前端
npx vite build      # 产物在 dist/web
```

### 8.2 生产（Windows）

| 脚本 | 作用 |
|---|---|
| `.tools/launch-server.mjs` | 拉起服务端 + 看门狗 |
| `.tools/watchdog.mjs` | 每 20 秒探 `/api/health`，连续 3 次失败自动重启 |
| `.tools/everony.ps1` | 一键开关（start / stop / status / toggle），带弹窗反馈 |
| 桌面 `Everony 开关.vbs` | 双击 = 在跑就停、没跑就起并打开网页 |
| `Startup\EveronyServer.vbs` | 开机自启，先起看门狗 |

**发布 = 重启这个进程**，不打包、不复制到别处。

### 8.3 公网访问

- 临时：`.tools/tunnel.mjs` 起 cloudflared 快速隧道，地址写进 `data/tunnel.json`（地址会变）。
- 长期：买域名 + 固定地址的机器 + 命名隧道或反代（进度见 `docs/20-公网访问与域名进度.md`）。

## 9. 版本与发布

- 版本号格式：`vYYYY.MM.DD.主.次.修`，每次发布按需递增，不跳号。
- 当前版本：**v2026.11.17.0.10.25**。
- 改版本时必须同步：`package.json` 的 `version`、`server/index.js` 的 `const VERSION`、`CHANGELOG.md` 标题、`README.md`、`AGENTS.md`、git tag。
- 发布前必须：语法检查 → 跑全部测试 → `vite build` → 重启 → `curl /api/health` 版本对得上 → 截图确认。

## 11. 演进时间线

| 阶段 | 版本 | 做了什么 |
|---|---|---|
| **自写服务端** | 0.7–0.8 | 放弃基于 Matrix 的改造方案，自己用 Fastify + SQLite 写服务端；账号、好友、私聊 |
| **群聊与 Bot** | 0.9 | 群聊、Bot 广场、OneBot 11 接入、Bot 用模型（BYOK） |
| **跨实例与中继** | 0.10.0–0.10.15 | 实例发现、跨网络加好友、中继兜底、桌面安装包与手机包 |
| **转向纯网页** | 0.10.16–0.10.18 | 决定不再分发安装包，一台服务器一个网址；广场首页化；Bot 免加好友可聊 |
| **手机与站长工具** | 0.10.19–0.10.24 | 访问入口卡片、外网隧道、看门狗、管理后台、注册审核、IP/设备识别、防攻击 |
| **门禁与身份收口** | 0.10.25（当前） | 注册门禁（邮箱码/邀请码）、邀请码管理、发信服务、注销冷静期、数据限期 14 天、号码搜索 + 个人二维码、Bot 密码登录、删掉实例互联与账号迁移、聊天去掉表情包与传文件 |

详细的版本变更看 `CHANGELOG.md`；用户原始需求与状态看 `docs/13-应用需求全量清单（原文版）.md`。

## 12. 现在能做什么 / 还不能做什么

### 能做

- 一台机器开站，别人用浏览器进来注册、加好友、私聊、建群。
- 公开 Bot 上广场，不用加好友就能直接聊。
- Bot 有号码、有密码，主人能登进去以 Bot 的身份改资料。
- 站长能管账号（封禁 / 删除）、管注册门禁、配发信、看登录流水、封 IP、生成邀请码。
- 数据有期限，超期自动清；注销有 1–3 天冷静期，可撤销。
- 手机「添加到主屏幕」当 App 用。

### 还不能

- 视频通话、屏幕共享。
- 消息端到端加密（当前是「数据只在自己服务器上」这一层保护）。
- 多台服务器之间的账号互通（跨实例那套已按用户要求整块移除，一台服务器就是一站）。
- 自动备份到云端（`server/backup.js` 只能导出到本机）。
