# 路线图

> 2026-11-13 修订：协议层改用 Matrix，工期与范围已重算。

## v0.1 — 单实例能聊天（目标 2–3 周）

**范围**

- tuwunel 起一个本地 homeserver
- sidecar：号码注册、好友申请、好友列表、Bot 归属、BYOK 配置、邮件队列
- 客户端：登录 / 注册 / 三栏界面 / 好友列表 / 申请中心 / 私聊 / Bot 创建向导
- AI 网关：接 OpenAI 兼容接口，Bot 能回复

**不做**：联邦、群聊、图片、主题切换、移动端

**验收（7 条）**

1. 一条命令起 tuwunel + sidecar + client
2. 邮箱注册，自选 6–9 位号码，得到 `@号码:本地域名`
3. 搜索号码加好友，对方收到申请卡片，同意后进好友列表
4. 互发消息，离线能收到，已读回执正常
5. 创建 Bot，填自己的 key，Bot 能回复
6. 别人加 Bot 需要主人审批，审批后能聊
7. 断网重连后消息不丢

## v0.2 — 跨实例互联 + 群聊（目标 2–3 周）

**范围**

- 两个实例之间加好友（sidecar 联邦接口 + Matrix 联邦密钥签名）
- Tailscale / 局域网两种组网方式
- 群聊（Matrix room + 好友映射）
- 跨实例 Bot 被加

**验收**

- 两台机器各起一个实例，A 实例的号能加 B 实例的号
- 群聊能拉人和 Bot

## v0.3 — 打磨（目标 2–3 周）

- 单文件可执行（Node SEA 或 bun compile）
- 图片消息
- 主题切换（Dawn / Void）
- 云中继（Cloudflare Worker）
- 导入导出

## 不做

- 移动端 App（先做响应式 Web）
- 语音视频
- 端到端加密（Matrix 有，但我们 v0.1 不开，开了 Bot 就读不到消息）
- 任何自动重启 / 看门狗机制

## 里程碑风险

| 风险 | 处理 |
|---|---|
| tuwunel 有未知 bug | 准备 Synapse 备用部署脚本 |
| 联邦要域名 + TLS | v0.2 才做，v0.1 只在本机 |
| matrix-js-sdk 学习成本 | 先照官方 quickstart 跑通一个最小客户端再动 UI |
